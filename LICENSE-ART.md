# Licence for the art in this mod

The **code** in this repository is MIT, as it says in `LICENSE`. That is
deliberate: it keeps the mod inside an ecosystem where the engine and every
other mod are permissive, and it lets anyone learn from it, fork it or borrow
a technique.

The **original artwork** in this repository is not code, and is licensed
separately:

**Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International**
(CC BY-NC-SA 4.0) — https://creativecommons.org/licenses/by-nc-sa/4.0/

That means, for the art:

- **Attribution** — say where it came from and who made it.
- **NonCommercial** — do not sell it, and do not sell a package whose value
  is this art.
- **ShareAlike** — if you change it and pass it on, pass it on under these
  same terms.

## What "the original artwork" covers

The wallpapers labelled `GEN3 BOX` in the WALLPAPER menu -- every scene drawn
in `main.lua` rather than loaded from a file. The drawing code is MIT like the
rest of the code; the pictures it produces are art, under the terms above.

## What it does not cover

Third-party art shipped alongside keeps **its own licence**, which is
recorded per item in `THIRD_PARTY_NOTICES.md`. Those licences — CC0 and
CC BY — are more permissive than this one, and nothing here restricts them:
if a file is listed there, its own terms are the ones that apply, and they
travel with it wherever it goes.

Nothing here restricts play. Install it, stream it, record it, take
screenshots, write about it. This asks one thing: do not sell somebody else's
Pokémon nostalgia back to them.
